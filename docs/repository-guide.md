# Project Files

Open `DIY-ATX-PSU.code-workspace` in VS Code. Open `README.md` and use Ctrl+Shift+V for the report preview. GitHub renders the relative image links and Mermaid block diagram.

Open `hardware/diy_atx_psu.kicad_pro` in KiCad. The schematic uses its adjacent `Project.kicad_sym` and `sym-lib-table`. It documents a panel/harness design, not a PCB layout. The [reading guide](schematic-guide.md) explains the sheet sections and symbols.

## Reading the report

Start with [README](../README.md) for the circuit explanation, calculations, parts list and conclusion. The `docs` folder contains the supporting notes and construction photographs.

Open [the schematic image](images/schematic/diy_atx_psu.svg) to view the circuit in a browser. Download the repository and open `hardware/diy_atx_psu.kicad_pro` to view or edit it in KiCad. Keep the files in `hardware` together so KiCad can find the symbol library.

The [test summary](testing.md) records the team's reported functional test results.

## Photographs

The construction photographs are in `docs/images`. The [photo index](evidence-register.md) describes each image.
